    API Reference

    CARESpixel

    setPixel property

    Accessor property to get PixelSetter instance.

    Example:

    cp = CARESpixel(pin=5, total_leds=64)
cp.setPixel[3](255, 0, 0)  # Set pixel 3 to red (dimmed)

    PixelSetter

    Helper class to set individual NeoPixel colors safely.

    __getitem__(pixel)

    Return a function that sets the color of the pixel at the given index.

    :param pixel: Integer index of pixel :return: Function(r, g, b) to set color

    Example:

    setter = cp.PixelSetter(cp.display, cp.total_leds)
set_pixel_5 = setter[5]
set_pixel_5(255, 0, 0)  # Set pixel 5 to red

    __init__(neopixel_obj, total_leds)

    Initialize PixelSetter helper.

    :param neopixel_obj: neopixel.NeoPixel instance :param total_leds: Number of LEDs in the matrix

    Demo()

    Run demo animation and faces.

    Example

    cp.Demo()

    __init__(pin, total_leds)

    Initialize the NeoPixel display.

    :param pin: A machine.Pin object or pin number (int). :param total_leds: Total number of LEDs in the matrix (max 64).

    Example

    cp = CARESpixel(pin=5, total_leds=64)

    Run animation sequence.

    Animate rain drops.

    OLED

    __init__(width=128, height=64, scl_pin=22, sda_pin=21, i2c_addr=60, spi=None, external_vcc=False)

    Initialize the OLED display using I2C (default) or SPI.

    Example:

    oled = OLED()

    blit(framebuffer, x=0, y=0)

    Copy framebuffer content to the display.

    Example:

    dummy_fb = framebuf.FrameBuffer(bytearray(1024), 128, 64, framebuf.MONO_VLSB)
oled = OLED()
oled.blit(dummy_fb, 0, 0)

    clear()

    Clear the display.

    Example:

    oled = OLED()
oled.clear()

    contrast(contrast)

    Set the contrast level.

    Example:

    oled = OLED()
oled.contrast(128)

    display_image(data)

    Display image data on the screen.

    Example:

    oled = OLED()
image = oled.load_image("logo.bin")
oled.display_image(image)

    display_image_from_bytes(image)

    Display image from bytearray.

    Example:

    image = bytearray(1024)
oled = OLED()
oled.display_image_from_bytes(image)

    fill(color)

    Fill the display with a single color (0 or 1).

    Example:

    oled = OLED()
oled.fill(1)

    fill_rect(x, y, w, h, color)

    Draw a filled rectangle.

    Example:

    oled = OLED()
oled.fill_rect(10, 10, 40, 20, 1)

    invert(invert)

    Invert display colors.

    Example:

    oled = OLED()
oled.invert(1)

    load_image(filename)

    Load an image from a file.

    Example:

    oled = OLED()
image = oled.load_image("logo.bin")

    poweroff()

    Turn off the display.

    Example:

    oled = OLED()
oled.poweroff()

    poweron()

    Turn on the display.

    Example:

    oled = OLED()
oled.poweron()

    vline(x, y, h, color)

    Draw a vertical line.

    Example:

    oled = OLED()
oled.vline(5, 0, 30, 1)

    write(text, x=0, y=0)

    Write text on the OLED display at position (x, y).

    Example:

    oled = OLED()
oled.write("Hello, World!", 10, 10)

    Pin

    __init__(pin_number, mode=machine.Pin.OUT)

    Initialize a pin for digital or analog operations.

    Parameters:

    Name Type Description Default
    pin_number int

    The pin number.

    		 required
    mode int

    Use Pin.IN or Pin.OUT for input or output mode.

    		 OUT

    Example:

    pin_in = Pin(12, Pin.IN)   # Initialize pin 12 as input
pin_out = Pin(14, Pin.OUT) # Initialize pin 14 as output

    analogRead()

    Read analog value (0-4095) if pin is input with ADC.

    Returns:

    Name Type Description
    int

    ADC reading value.

    Example:

    pin = Pin(34, Pin.IN)
value = pin.analogRead()
print("ADC value:", value)

    analogReadVoltage(reference_voltage=3.3)

    Convert ADC reading to voltage.

    Parameters:

    Name Type Description Default
    reference_voltage float

    Reference voltage, default is 3.3V.

    		 3.3

    Returns:

    Name Type Description
    float

    Voltage value.

    Example:

    pin = Pin(34, Pin.IN)
voltage = pin.analogReadVoltage()
print("Voltage:", voltage)

    analogWrite(value)

    Write PWM duty cycle to pin (0-255) if configured as output.

    Parameters:

    Name Type Description Default
    value int

    PWM duty cycle between 0 and 255.

    		 required

    Example:

    pin = Pin(14, Pin.OUT)
pin.analogWrite(128)  # Set PWM to about 50% duty cycle

    digitalRead()

    Read digital value (0 or 1) if pin is input.

    Returns:

    Name Type Description
    int

    Digital pin value (0 or 1).

    Example:

    pin = Pin(12, Pin.IN)
val = pin.digitalRead()
print("Digital value:", val)

    digitalWrite(value)

    Write digital value (0 or 1) if pin is output.

    Parameters:

    Name Type Description Default
    value int

    0 or 1 to set pin low or high.

    		 required

    Example:

    pin = Pin(14, Pin.OUT)
pin.digitalWrite(1)  # Set pin high
pin.digitalWrite(0)  # Set pin low

    Servo

    __init__(pin, freq=50)

    Initialize a servo motor.

    :param pin: A Pin object (your custom Pin class) or machine.Pin instance. :param freq: PWM frequency in Hz (default 50).

    Example:

    servo5 = Servo(Pin(5))          # Using your custom Pin class
servo15 = Servo(machine.Pin(15))  # Using machine.Pin directly

    write_angle(angle)

    Set the servo angle between 0 and 180 degrees.

    :param angle: Integer angle (0 to 180).

    Example:

    servo5 = Servo(Pin(5))
servo5.write_angle(90)  # Move servo to 90 degrees
servo5.write_angle(0)   # Move servo to 0 degrees

    sevenSegment

    __init__(clkPin=22, dioPin=21, bitDelay=100)

    Initialize the sevenSegment display.

    :param clkPin: Clock pin number (default 22). :param dioPin: Data pin number (default 21). :param bitDelay: Delay in microseconds for communication (default 100).

    Example:

    segment = sevenSegment(clkPin=5, dioPin=4)
OR
segment = sevenSegment()

    displayColon(state, brightness=7)

    Turn the colon on or off.

    :param state: 1 to turn colon on, 0 to turn off. :param brightness: Brightness level (0 to 7).

    Example:

    segment.displayColon(1)  # Turn colon on
segment.displayColon(0)  # Turn colon off

    displayDigit(inputValue, brightness=7)

    Display a number or string on the 4-digit 7-segment display.

    :param inputValue: int or str (max 4 digits/characters). :param brightness: Brightness level (0 to 7).

    Example:

    segment.displayDigit(1234)
segment.displayDigit("AbCd")

    encodeCharacter(char)

    Encode a character to its 7-segment byte representation.

    :param char: Character to encode. :return: Byte representing the segments.

    Example:

    byte_val = segment.encodeCharacter('A')
print(bin(byte_val))

    setSegments(segments, colon=False, brightness=7)

    Set the segments on the display.

    :param segments: List of 4 bytes, each representing segments for a digit. :param colon: Boolean, True to turn colon on. :param brightness: Brightness level (0 to 7).

    Example:

    segments = [0x3F, 0x06, 0x5B, 0x4F]  # Displays "0123"
segment.setSegments(segments, colon=True, brightness=5)

    start()

    Start communication with the display.

    stop()

    Stop communication with the display.

    writeByte(data)

    Send a byte to the display.

    :param data: Byte data to send.

    Example:

    segment.writeByte(0xFF)

    write_colon(state, brightness=7)

    Control colon display.

    :param state: 1 to turn colon on, 0 to turn off. :param brightness: Brightness level.

    Example:

    segment.write_colon(1)

    write_digit(inputValue, brightness=7)

    Display digit(s) using displayDigit.

    :param inputValue: int or str. :param brightness: Brightness level.

    Example:

    segment.write_digit(5678)
